 📊 Binance Trade Analysis 🚀  

This project analyzes **90 days of Binance trade data** to compute key financial metrics and rank accounts based on performance.  

 📌 Project Overview  
The analysis involves:  
✅ Cleaning and processing Binance trade data  
✅ Computing key financial metrics such as ROI, PnL, Sharpe Ratio, and Maximum Drawdown  
✅ Ranking accounts based on performance using a weighted scoring algorithm  
✅ Identifying the **top 20 best-performing accounts**  


 📊 Key Metrics Calculated  
| Metric | Description |
|--------|------------|
| ROI (Return on Investment) | Measures profitability relative to initial investment |
| PnL (Profit and Loss) | Overall monetary gain or loss over the 90-day period |
| Sharpe Ratio | Assesses risk-adjusted returns |
| Maximum Drawdown (MDD) | Measures the largest peak-to-trough drop |
| Win Rate | Percentage of profitable trades |
| Winning Positions | Number of trades that ended in profit |
| Total Positions | Total number of trades executed |
